# Python Day 133 - Difference Between Two Lists

This Python program finds the elements present in the first list but not in the second list.

## Example

First list:
```text
[10, 20, 30, 40, 50]
```

Second list:
```text
[30, 40, 50, 60, 70]
```

Output:
```text
Difference: [10, 20]
```

## Concepts Used

- Lists
- `for` loop
- `if` statement
- `not in` operator
- `append()` method

## How It Works

The program checks each element in the first list. If an element is not present in the second list, it adds that element to the difference list.
